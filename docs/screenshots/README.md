# Gameplay screenshots

These are unmodified captures from the native Linux and Android builds.
The original Linux gallery captures use Vulkan on an NVIDIA RTX 4070 Laptop GPU,
captured on 2026-10-31, with the footer-free character selection updated on 2026-11-01.
The original Android emulator capture is from 2026-11-02. Additional feature
captures were selected from saved development runs on 2026-11-03. They document
the recomp's output; the game artwork is from Shadow Fight 2.
The Settings image was recaptured from the current Linux build on 2026-11-03
using Mesa lavapipe, with the bottom controller hints hidden.
