SF2Recomp

1. Extract this entire folder to a writable location. Keep its contents together.
2. Open sf2recomp.exe on Windows, SF2Recomp.app on macOS, or sf2recomp on Linux.
3. In the converter window, browse for your NSP, prod.keys and output folder.
   For extracted updated files, select "Extracted game folder" as the input type.
4. Click Convert. The window shows progress and the full log. Each conversion
   also saves an sf2recomp-conversion-<timestamp>.log in the tool's logs folder.
5. When conversion finishes, click Open output folder. Open sf2.exe on Windows,
   the generated desktop launcher on Linux, or Shadow Fight 2.app on macOS.
   The latest game log is logs/shadow-fight-2.log in the converted folder.

On Linux, run ./sf2recomp --install-desktop to add the converter to the app menu.
On macOS, keep each .app with the rest of its folder.

Supported input: Shadow Fight 2 combined base + v1.1.0/update v131072 NSP,
including its CNMT XML sidecars and tickets. Other NSP layouts and NSZ are not
supported. Already extracted updated files can be supplied with --game instead.
No game data or keys are included. Conversion and game data remain local.

Command-line examples (Windows: replace ./sf2recomp with sf2recomp.exe):

  In interactive Command Prompt, use start "" /wait sf2recomp.exe --check
  when you need the prompt to wait for completion.

  ./sf2recomp --version
  ./sf2recomp --check
  ./sf2recomp --cli
  ./sf2recomp --nsp "/path/game.nsp" --keys "/path/prod.keys" --output "/path/SF2" --play
  ./sf2recomp --game "/path/extracted/update" --output "/path/SF2"

Android is optional. Choose Android phone (ARM64) under Convert for, read and
accept the SDK terms in the window, then click Convert. Or run:

  ./sf2recomp --android --nsp "/path/game.nsp" --keys "/path/prod.keys" --output "/path/APK" --accept-android-licenses

Read Google's SDK terms before using --accept-android-licenses:
https://developer.android.com/studio/terms

Android setup downloads several GB on first use. SDK, NDK, Java, Gradle, signing
key and caches stay under extensions/android in this tool folder. Later builds
reuse them. No Android Studio or system SDK installation is required. Install the
resulting private APK on your phone. The default APK targets 64-bit ARM phones;
--abi x86_64 targets an emulator. The phone requires Android 13+ and compatible
Vulkan 1.3 features. Cross-device LAN combat still needs validation.

Desktop conversion includes Python, input helpers and a compiler. You still need
a supported OS, sufficient free disk space and a compatible Vulkan 1.3 GPU/driver.
Desktop release baselines are Linux with glibc 2.39+ (Ubuntu 24.04 or newer),
Windows 10/11 x64, and macOS 15+ on Apple Silicon.
Windows/macOS gameplay support remains experimental. On macOS, unsigned downloads
may require opening through the system's Security settings.

LAN: use the same SF2Recomp release and matching roster settings on both devices.
Tool version, LAN packet protocol and simulation compatibility are separate
checks. The original game's v1.1.0 version is independent of the tool version.

Project and documentation: https://github.com/bipinkrish/sf2recomp
