# Project icon

`sf2recomp.png` is the original icon selected by the project owner from
[SteamGridDB](https://cdn2.steamgriddb.com/icon/2b4a378ec7e82d072253e1a1de3052aa.png).
It is white artwork with a transparent background. The converter displays it
against a dark tile and uses it as the window icon.

`sf2recomp.ico` contains Windows icon sizes from 16 to 256 pixels.
`sf2recomp-readme.png` adds a dark background so the white icon stays visible in
both light and dark README themes. Regenerate both with
`python3 tools/prepare_icon.py`, which requires Pillow.

The artwork retains its original owners' rights and is separate from the project's
MIT-licensed code. Converted games retain their official icon from the user's
game files.
